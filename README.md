# 📚 Deep Learning Books — Weekly Book Reviews

Every week I review one well-regarded book on deep learning and AI.
For each book I cover:

- What the book is and who wrote it
- Who it is for (and its prerequisites)
- What you will learn
- A short summary of every chapter
- Links to official resources and companion code

> ⚠️ **Copyright note:** PDFs of copyrighted books are **not** uploaded to this repository.
> Only a some sections, reviews, chapters, and links to official sources (publisher / authors' repo) are included.

## ➕ Adding a New Book

1. Create a new folder: `books/NN-book-name/`
2. Copy `TEMPLATE.md` to that folder as `README.md` and fill it in.
3. Add a new row to the table above.
4. Commit and push.
